## Calculator - Project made for The Odin Project Foundations Curriculum 




This is a simple calculator project made for the odin project foundations final project, while it is a simple project but covers foundational JavaScript concepts that will be used as a building blocks from small to bigger projects, from those foundational concepts this project have touched these:

- String Operations
- Conditional Statements 
- Arrays
- Functions
- Objects

>**Disclaimer**
>
>This calculator will not accept number greater than 12 Digits since digits more than 16 or 17 are BigInt and they yeld unexpectedly results.
